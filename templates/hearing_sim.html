為什麼「聽得到，卻聽不清楚」Why It Happens

年紀增長造成的聽力變差，通常是高音先變差。說話時，母音（ㄚ、ㄛ、ㄧ）比較低、比較大聲，子音（ㄙ、ㄘ、ㄈ、ㄒ、ㄑ）比較高、比較小聲；高音聽不到時，就會覺得對方有在說話，卻分不出「四」和「十」、「吃飯」和「洗碗」。

所以把電視、說話的音量開大，只是讓聽得到的部分更大聲，聽不到的高音還是聽不到。環境一吵，背景聲又會蓋過本來就聽不太到的字音，在餐廳、家族聚會時特別吃力。

常見的跡象包括：電視開得比家人習慣的大聲、常說「蛤？」、講電話聽不清楚、在人多的地方不太說話、沒注意到門鈴或電器的嗶聲。

和聽力變差的家人說話Talking Tips

{{ icon("users", "ico-big") }}

面對面、先叫名字

讓對方看得到您的臉和嘴型，先叫名字再開始說，不要在背後或別的房間喊。

{{ icon("clock", "ico-big") }}

放慢、清楚，不用大吼

稍微放慢、一句一句說清楚。大吼會讓聲音變形，反而更難聽懂，也容易讓人覺得被兇。

{{ icon("quiet", "ico-big") }}

關小背景聲

說話時先把電視、收音機關小；在餐廳選安靜的角落，讓長輩坐在背對吵雜的位置。

{{ icon("refresh", "ico-big") }}

換句話說

沒聽懂時，換個說法比一直重複同一句有用；重要的事（時間、地點、數字）可以寫下來。

{{ icon("check", "ico-big") }}

確認聽懂了

說完重要的事，請對方說一次給您聽，比問「有聽到嗎」更準。

{{ icon("ear", "ico-big") }}

陪著一起面對

聽力變差很常見，不是誰的錯。可以陪家人一起做聽力測驗、一起到門市了解。

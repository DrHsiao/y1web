## 新增：會員（用 LINE 或 Google 登入）

加入會員不是必要的：不登入也能使用本網站和每日聽練的所有功能。登入只是為了保存紀錄、換手機也不會不見，以及查看您在門市的資料。

**登入時本門市會拿到**
- LINE 登入：LINE 提供的帳號代號和顯示名稱。不會取得您的 LINE Email、電話或好友名單。
- Google 登入：Google 提供的帳號代號、名稱和 Email。
- 本門市不會拿到您的密碼，也不會用您的帳號發文，或讀取聯絡人、照片、雲端硬碟。
- LINE 的同意畫面會問您要不要加入本門市的 LINE 官方帳號好友，由您決定。

**登入狀態**
- 登入後，您的瀏覽器會存一組登入憑證（Cookie），本門市只保存它的加密雜湊。180 天沒有使用就會失效。
- 為了讓您在「會員帳號」頁看到哪些裝置正在登入，會記錄瀏覽器的版本說明，以及最後使用的日期。

**連結門市客戶資料**
- 只有您勾選同意後才會連結，並記錄同意的時間。
- 連結的方式有兩種：
  - 如果您的 LINE 已經在門市綁定過，用 LINE 登入後可以直接比對；
  - 其他情況由門市人員確認是您本人後再連結。
- 連結後，會員頁只顯示您的稱呼、預約、保養提醒和每日聽練紀錄。
- 聽力檢查結果、購買紀錄、身分證字號、生日、地址、電話**不會**顯示在網站上。網站的系統也讀不到這些資料。
- 您可以隨時在「會員帳號」頁解除連結。

## 新增：每日聽練

- **沒有登入**：練習紀錄只存在您這台裝置的瀏覽器裡，不會上傳。
- **登入會員後**：練習紀錄會保存到您的會員裡，每次打開和練完時同步。內容包括：
  - 練習的日期和每天練了幾回；
  - 經驗值、各項練習的等級、連續打卡天數的最高紀錄；
  - 調整音量的日期。
  - 不包含您每一題的作答，也不會錄音。
- 每日聽練是聽覺練習，不是聽力檢查，本門市不會用練習紀錄判斷您的聽力。
- 如果會員已經連結門市客戶資料，門市人員可以在您的客戶資料裡看到練習摘要（例如最近練習的日期和等級），在回診時關心您的使用情形。
- 在每日聽練按「清除這台裝置的練習紀錄」，只會清除這台裝置上的紀錄。要刪除會員裡的紀錄，請刪除會員（見下方）。

## 新增：Cookie 與瀏覽器儲存

- 本網站的 Cookie 只用在會員登入，以及登入過程中的安全檢查（10 分鐘內失效）。
- 字的大小、深色模式的設定，以及沒登入時的每日聽練紀錄，都存在您的瀏覽器裡，本門市看不到。
- 本網站不使用廣告或追蹤用的 Cookie。

## 修改：如何刪除您的資料

在原本的段落前面加上：

> **會員**：在「會員帳號」頁按「刪除會員」，會立即刪除您的登入方式、練習紀錄、登入憑證和連結申請，而且不能復原。門市的客戶資料依原本的規定保存，不受影響。
> 您也可以到 Google 帳戶的「第三方應用程式和服務」，或 LINE 的「設定 → 帳號 → 已授權的應用程式」，取消授權本網站。取消授權後就不能再用那個帳號登入，但不會刪除會員資料；要刪除，請用「刪除會員」，或聯絡門市。

## 修改：用途

改成：

> 只用於聯絡您、安排門市或到府服務、傳送預約提醒，以及提供會員登入、保存每日聽練紀錄、在會員頁顯示您的門市資料。不會提供給第三方作行銷用途。

## 修改：保存與存放

改成：

> 資料存放在本門市自己的主機上，不使用外部表單服務。會員資料保存到您刪除會員為止。
> 本網站透過 Cloudflare 提供加密連線與防護，Cloudflare 會處理連線的網路位址等技術資料。本網站不使用 Google Analytics 等第三方追蹤工具。

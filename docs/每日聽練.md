# 每日聽練（測試版）

> 2026-10-29 建立。John：「想做一個可以獨立出來的聽力練習主題，暫時依附在韻譯主網站。每日打卡，大約 1~3 分鐘的簡單練習。
> 提供網頁記憶或 Google 帳戶記憶成績，類似 Duolingo 的風格。以後可以移轉至 app。」
> 網址：`/practice/`（區網 http://192.168.1.88:8006/practice/）。測試期間 noindex、不放選單。

## 1. 做法

- **自成一格的資料夾** `practice/`：`index.html`、`practice.js`、`practice.css`、`manifest.webmanifest`、`sw.js`、圖示、
  `audio/digits/0–9.wav`（從 `static/audio/din/` 複製；換數字錄音時兩邊都要換，`sw.js` 的 CACHE 版本號加一）。
  路徑一律相對、不用官網樣板；只有「說明」頁連回 `/` 和 `/hearing-test`。官網只在 `app/main.py` 加了 mount 和 noindex。
- **一回 15 題、約 2 分鐘**：聽數字（雜音裡聽一個數字）、高低音（兩個音哪個高）、數聲音（響了幾聲）各 5 題，種類順序每回打亂。
  每種各有 Lv1–10：連續答對 2 題升一級、答錯降一級。難度表在 `practice.js` 開頭（`DIGIT_SNR`、`PITCH_PCT`、`COUNT_IOI`）。
- **打卡**：練完一回＝今天打卡；連續天數（今天還沒練就從昨天算）、本週七天、經驗值（答對 10、練完 20）。
  答錯可以「聽正確的」（數字不加雜音、高低音亮出答案、數聲音放慢一聲一個點）。
- **音量**：每天第一回先調音量，用最大聲的一級（Lv1）試聽，練習時不會比試聽更大聲；輸出接限幅器。聲音兩耳相同，喇叭也能練。
- **用語**：這是「練習」，不是檢查，不宣稱效果（醫療器材廣告限制）；說明頁有就醫提醒。

## 2. 紀錄存在哪裡

- 沒登入：只存在瀏覽器（localStorage `y1-practice`）。資料格式：
  `{ v, days: { "YYYY-MM-DD": { n, xp, t?, s? } }, lv: { digit, pitch, count }, best, vol }`。
  - `t`（當天練了幾秒，一回最多算 10 分鐘）、`s`（各項 `{ q 題數, r 答對, lv 當天練完的等級 }`，沒練到的項目不放）是 **2026-11-02** 加的：
    John 要門市人員「盡可能看見所有練習細節」。舊紀錄沒有這兩項；合併時每一項都取較大，`merge()` 仍可交換、重複合併不變。
  - 不記每一題的題目和選的答案（資料量大、也比較像檢查）。要的話再談，隱私權政策要跟著改。
  - 每份上限 800KB（`progress.MAX_BYTES`，4000 天全有細項約 600KB；.26 nginx 預設上傳上限 1MB），備份碼長度上限跟著放寬。
- 換手機：「備份碼」（`Y1P1-` 加 base64 JSON）。匯入是**合併**（每天取較多、等級取較高；順序無關、重複合併不變），不會蓋掉。
  讀進來的資料一律經過 `clean()` 重新整理（備份碼是使用者貼的，視為不可信）。
- **會員同步（✅ 2026-11-01）**：原本計畫存在使用者自己的 Google 雲端硬碟，改成官網會員。用 LINE 或 Google 登入後，打開和練完時和伺服器合併（同一個 `merge()`），換手機、多台裝置都同步；沒登入照舊存在瀏覽器、可用備份碼。做法見[會員系統](會員系統.md) 2.5 與第 7 節。不用雲端硬碟權限，CSP 也不用放行外部網域。
  隱私權政策的「會員」「每日聽練」段落 ✅ 11-02 上線（`/privacy#member`、`#practice`）。

## 3. 之後

- **題目**：聲調（媽／麻／馬／罵）、相似字（四／十、七／一）、雜音裡聽一句話、生活聲音（門鈴、電話、熱水壺）。都需要錄音：
  用 Google TTS（同數字錄音的 Wavenet-A）或門市自己錄；生活聲音要確認授權。
- **App**：現在已經是 PWA（https 下可以「加到主畫面」、離線可練）。上架時用 Capacitor 包同一個資料夾（iOS／Android），
  Google 登入改用原生外掛，`merge()` 和資料格式不變。也可以先用 TWA 上 Google Play。
- **獨立網域**：資料夾搬到新網域即可；說明頁的兩個門市連結改成完整網址。
- 上線前：放進官網選單／首頁、拿掉 noindex、sitemap。

## 4. 參考：interton「耳力健身房」（2026-10-29 看過）

https://interton.com.tw/hearing/ 。只參考做法，**題庫、文字、聲音都要自己做，不抄**。
- 它有：5 個華語語音單元（噪音中聽句子、快語速、聽覺記憶、缺字推理、相似音辨識），每天 30 題約 10–15 分鐘；
  開源語音模型 Kokoro 合成 5 種聲音（男、女、兩種長輩、小孩，可輪流）；背景是多人說話聲；
  進度頁（各單元每次平均等級的折線、和上次比、最近 7 天比前 7 天）；相似音按類別（聲調、捲舌、ㄣ／ㄥ、送氣、
  高頻子音、數字）統計常錯的音，附生活應對小技巧；等級換算成白話（「多承受約 2 dB 的噪音」「聽懂 1.5 倍速」）；
  字體大小、每單元題數設定；說明寫明「正確率停在七成是刻意的」「戴著平常的助聽器練」「每週 5 天、4–8 週」。
  門市發啟用碼（有期限、到期前 14 天提醒回門市）。設定檔的店名寫「睿聲助聽器／瑞聲聽力中心」。
- 它沒有：每日打卡／連續天數、換手機備份、離線（沒有 service worker）。啟用碼在瀏覽器端驗證——我們如果要做啟用碼，要放伺服器驗。
- 我們可以學（建議順序）：
  1. 小改：提示改成「平常有戴助聽器就戴著練、用喇叭」；完成畫面說明七成正確是剛好的難度；等級換成白話；字體放大；每種題目可單獨練。
  2. 進度頁：用 `days[日期].s`（11-02 起有各項當天的題數、答對、等級）畫折線、和上週比。
  3. 華語語音題：先做「相似音辨識」（只要詞，類別統計＋小技巧＋「一直聽錯高頻音可回門市調整」），再做「噪音中聽句子」。
     題庫自己寫（生活、醫療、購物），聲音用本機 Kokoro（CPU、nice）產生多種聲音，多人說話背景也用自己合成的。
     每天仍維持 2–3 分鐘：每天輪 3 種題目，想多練再單獨練。
